# Fonts Directory

Place the required font files here:

## Cairo (for Arabic)
- Cairo-Regular.ttf
- Cairo-Bold.ttf
- Cairo-SemiBold.ttf
- Cairo-Light.ttf

Download from: https://fonts.google.com/specimen/Cairo

## Poppins (for English/Latin)
- Poppins-Regular.ttf
- Poppins-Bold.ttf
- Poppins-SemiBold.ttf
- Poppins-Light.ttf

Download from: https://fonts.google.com/specimen/Poppins

These fonts are used via Google Fonts package as fallback, but including local assets improves performance and offline support.

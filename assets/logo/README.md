# Logo Assets

Place the Qari2 app logo here:

- `qari2_logo.png` - Main app logo (512x512 or higher resolution)

## Logo Design Specs

- Style: Abstract open book with stylized Arabic letter "ق"
- Colors: Gradient from Ink Blue (#1E3A5F) to Emerald Green (#00A676)
- Format: PNG with transparency
- Recommended size: 512x512px or 1024x1024px
- Shape: Rounded square for app icon

The logo should be created by a designer following the brand guidelines in the main README.
